# Plan 08-01: GitHub Discovery, Activity Tracking & Analytics Engine (`integrations/github_watch.py`, `services/github_intelligence.py`)

## Goal
Implement full GitHub intelligence layer in `services/github_intelligence.py` and `integrations/github_watch.py`: auto-discovery of personal/private/org repos, open PR & unreviewed PR tracking, commit time-series analytics (month/year), actionable commit diff URLs, and SQLite findings persistence (`SEC-07`).

## User Review Required
> [!IMPORTANT]
> GitHub secret scanner findings must strictly persist redacted previews (`AKIA...`) and actionable commit diff links (`https://github.com/{repo}/commit/{sha}`). Never store raw secrets.

### Component 2: GitHub Intelligence Service

#### [NEW] [`services/github_intelligence.py`](file:///Users/somespecies/Desktop/Evie/services/github_intelligence.py)
- `sync_github_intelligence(db_path, token_key)`: Discovers all user/org repos, scans activity and secret findings, persists to SQLite `github_events` & `secret_findings`.
- `get_repository_analytics(db_path)`: Returns commit counts by month/year, total repos monitored, and active PRs.
- `get_unreviewed_prs(db_path)`: Returns open unreviewed PRs requiring attention.
