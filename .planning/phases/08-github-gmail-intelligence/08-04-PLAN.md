## Proposed Changes

### Component 1: Conversational Intelligence Engine

#### [NEW] [`services/conversational_router.py`](file:///Users/somespecies/Desktop/Evie/services/conversational_router.py)
- Implement `parse_user_intent(message)`: Uses structured prompt/JSON classification to identify intent (`github_commits`, `github_secrets`, `github_prs`, `gmail_promotional`, `gmail_phishing`, `combined_briefing`, `greeting`, `unknown`) and entities (`repo_name`, `time_range`).

### Component 2: 24/7 Asynchronous & Incremental Monitoring Engine

#### [MODIFY] [`services/github_intelligence.py`](file:///Users/somespecies/Desktop/Evie/services/github_intelligence.py)
- Add `github_sync_state` table schema (`repo_name TEXT PRIMARY KEY, last_pushed_at TEXT, last_scanned_sha TEXT`).
- Implement incremental repository scanning check: compare GitHub API `pushed_at` timestamp with stored `last_pushed_at`. Skip commit/patch fetching entirely if `pushed_at <= last_pushed_at`.
- Only fetch diffs for new commits since `last_scanned_sha`.

#### [MODIFY] [`services/gmail_intelligence.py`](file:///Users/somespecies/Desktop/Evie/services/gmail_intelligence.py)
- Add `gmail_sync_state` table schema (`last_internal_date INTEGER`).
- Filter metadata fetching to messages newer than `last_internal_date` to prevent re-processing existing inbox metadata.

#### [MODIFY] [`main.py`](file:///Users/somespecies/Desktop/Evie/main.py)
- Update `POST /integrations/sync` to execute `sync_all_real_integrations` asynchronously using FastAPI `BackgroundTasks`.
- Return HTTP 202 Accepted (`{"status": "sync_started", "message": "Background integration sync started"}`) immediately.
