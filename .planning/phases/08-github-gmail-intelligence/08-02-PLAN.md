# Plan 08-02: Read-Only Gmail Intelligence, Categorization & Recommendation Engine (`integrations/phishing_scan.py`, `services/gmail_intelligence.py`)

## Goal
Implement Gmail inbox intelligence service in `services/gmail_intelligence.py`: read-only metadata ingestion (`format=metadata`), email categorization (`important`, `phishing_alert`, `newsletter_promotional`), sender frequency analytics, cleanup recommendations, and proposal-confirmation gated cleanup endpoints (`MAIL-01`).

## User Review Required
> [!IMPORTANT]
> Unsubscribe or cleanup recommendations must produce a proposal card requiring explicit user confirmation (`/gmail/confirm_cleanup`) before performing any action. Never automatically delete or unsubscribe emails.

### Component 2: Gmail Intelligence & Cleanup Recommendation Service

#### [NEW] [`services/gmail_intelligence.py`](file:///Users/somespecies/Desktop/Evie/services/gmail_intelligence.py)
- `init_gmail_tables(db_path)`: Initialize `gmail_metadata` and `gmail_cleanup_proposals` SQLite tables.
- `sync_gmail_intelligence(db_path)`: Fetches live headers via `fetch_gmail_messages()`, categorizes emails, persists metadata, and updates sender frequency statistics.
- `get_inbox_intelligence_summary(db_path)`: Returns breakdown of important, phishing, and promotional email counts.
- `propose_gmail_cleanup_action(db_path, sender_domain, action_type)`: Generates proposal token for unsubscribe/cleanup recommendations.
- `confirm_gmail_cleanup_action(db_path, proposal_token, confirmed)`: Atomic SQLite execution claim for confirmed proposals.
