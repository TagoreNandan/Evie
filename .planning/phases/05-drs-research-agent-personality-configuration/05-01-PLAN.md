# Plan 05-01: DRS Research Agent (`drs.py`)

## Goal
Implement `drs.py` providing evidence-based Decision Research Support query execution, source attribution, non-definitive disclaimer framing, and `POST /drs/ask` endpoint (`DRS-01`).

## User Review Required
> [!IMPORTANT]
> - DRS answers MUST always be framed as evidence-based support, never as a definitive final verdict.
> - Every successful DRS response MUST include cited sources (URLs) and the mandatory non-definitive disclaimer.
> - If search results are empty or unavailable, return an honest `insufficient_evidence` response rather than a fabricated answer.

## Proposed Changes

### Component 1: DRS Research Engine

#### [NEW] [`drs.py`](file:///Users/somespecies/Desktop/Evie/drs.py)
- Create module docstring referencing `DRS-01` and Section 8 of `02_TRD.md`.
- Constant: `DISCLAIMER_TEXT = "Note: This analysis represents evidence-based support from available sources, not a definitive verdict."`.
- Implement `init_drs_table(db_path: str = "evie.db") -> None`:
  Create `drs_queries` SQLite table per `04_Backend_Schema.md`.
- Implement `ask_drs_question(question: str, db_path: str = "evie.db", search_fn = None) -> dict`:
  - Validate non-empty `question`.
  - Execute web search / evidence retrieval using `search_fn` (or default search aggregator).
  - If search returns 0 results or fails:
    - Log query to `drs_queries` table with status `"insufficient_evidence"`.
    - Return `{"question": question, "status": "insufficient_evidence", "summary": "Insufficient search evidence found to answer this question.", "sources": [], "disclaimer": DISCLAIMER_TEXT}`.
  - Synthesize findings into key evidence points and summary string.
  - Ensure zero absolute words (`"definitely"`, `"undoubtedly"`, `"100% proven"`) in generated summary/points.
  - Extract list of cited source URLs.
  - Log query to `drs_queries` SQLite table (`question`, `answer_summary`, `sources` as JSON array string).
  - Return `{"question": question, "status": "success", "summary": summary, "evidence_points": evidence_points, "sources": sources, "disclaimer": DISCLAIMER_TEXT}`.
