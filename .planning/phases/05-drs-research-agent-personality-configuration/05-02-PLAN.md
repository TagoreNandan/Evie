# Plan 05-02: Assistant Personality & Tone Configuration (`tone.py`)

## Goal
Implement assistant personality and tone configuration (`tone.py`), SQLite `user_config` persistence, and `POST /config/tone` & `GET /config/tone` endpoints (`TONE-01`).

## User Review Required
> [!IMPORTANT]
> - Tone preference is persisted in SQLite `user_config` (single-row table with `id = 1`).
> - Supported tone preferences: `'neutral'`, `'casual'`, `'formal'`, `'humorous'`.

## Proposed Changes

### Component 1: Personality & Tone Manager

#### [NEW] [`tone.py`](file:///Users/somespecies/Desktop/Evie/tone.py)
- Create module docstring referencing `TONE-01` and Section 4 of `02_TRD.md`.
- Implement `init_user_config_table(db_path: str = "evie.db") -> None`:
  Ensure `user_config` SQLite table exists and single default row (`id = 1`, `tone_preference = 'neutral'`) is initialized.
- Implement `get_tone_preference(db_path: str = "evie.db") -> str`:
  Query `user_config` table for `tone_preference`. Returns string (default `'neutral'`).
- Implement `set_tone_preference(tone: str, db_path: str = "evie.db") -> str`:
  - Validate `tone` in `['neutral', 'casual', 'formal', 'humorous']`. If invalid, raise `ValueError`.
  - Update `user_config` table where `id = 1`.
  - Return updated `tone`.
- Implement `apply_tone(text: str, tone: str | None = None, db_path: str = "evie.db") -> str`:
  - Retrieve `tone` via `get_tone_preference()` if `tone` parameter is None.
  - Apply conversational tone styling:
    - `'neutral'`: Returns clean, standard text.
    - `'casual'`: Prepends friendly greeting and appends casual closing.
    - `'formal'`: Applies professional formal formatting.
    - `'humorous'`: Adds witty, lighthearted commentary prefix/suffix.

### Component 2: FastAPI Route Integration

#### [MODIFY] [`main.py`](file:///Users/somespecies/Desktop/Evie/main.py)
- Implement `POST /config/tone`:
  - Accept request body JSON `{"tone_preference": str}`.
  - Call `tone.set_tone_preference(...)`.
  - Return HTTP 200 JSON with updated tone preference.
- Implement `GET /config/tone`:
  - Call `tone.get_tone_preference()`.
  - Return HTTP 200 JSON with active tone preference.
