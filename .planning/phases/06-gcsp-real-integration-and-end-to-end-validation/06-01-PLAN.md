# Plan 06-01: Real Integration Adapters & Google OAuth Refresh (`services/real_integrations.py`)

## Goal
Implement `services/real_integrations.py` providing real API integration adapters for GitHub, HIBP, Google Drive/Calendar, and Gmail, with automatic OAuth token refresh and zero-secret leakage error handling (`SEC-06`).

## User Review Required
> [!IMPORTANT]
> - All API keys and OAuth tokens are retrieved exclusively from OS Keyring (`keyring_utils.py`).
> - Google OAuth application must have publishing status "Production" to maintain permanent refresh token validity.
> - Zero raw credentials or authorization tokens permitted in logs, exceptions, or database tables.

## Proposed Changes

### Component 1: Real Integration Service Adapter

#### [NEW] [`services/real_integrations.py`](file:///Users/somespecies/Desktop/Evie/services/real_integrations.py)
- Create module docstring referencing `SEC-06` and Section 3 of `02_TRD.md`.
- Implement `refresh_google_oauth_token(db_path: str = "evie.db") -> Optional[str]`:
  - Fetch `google_oauth_client_id`, `google_oauth_client_secret`, and `google_oauth_refresh_token` from OS Keyring.
  - If missing, return None.
  - Request fresh access token from Google OAuth token endpoint (`https://oauth2.googleapis.com/token`).
  - Return access token string on success; handle HTTP errors safely by logging redacted message.
- Implement `fetch_github_telemetry(repo: str) -> dict`:
  - Retrieve `github_pat` from OS Keyring.
  - Query GitHub REST API (`/repos/{repo}/commits` & `/repos/{repo}/issues`).
  - Redact header tokens in any caught HTTP errors. Return structured dictionary.
- Implement `fetch_hibp_breaches(email: str) -> list`:
  - Retrieve `hibp_api_key` from OS Keyring.
  - Query HIBP v3 API (`/api/v3/breachedaccount/{email}`).
  - Handle rate limits (HTTP 429) gracefully by returning structured rate-limit finding.
- Implement `fetch_google_drive_exposures() -> list`:
  - Use `refresh_google_oauth_token()`. Query Google Drive API v3 (`/files`) for public or domain-wide shared files.
