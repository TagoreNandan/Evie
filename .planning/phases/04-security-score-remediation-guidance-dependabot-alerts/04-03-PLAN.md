# Plan 04-03: Read-Only Gmail Phishing Pattern Analyzer (`integrations/phishing_scan.py`)

## Goal
Implement read-only Gmail phishing pattern analyzer (`integrations/phishing_scan.py`) (`SCORE-04`) to detect suspicious email headers, domain mismatches, and urgent phishing indicators.

## User Review Required
> [!IMPORTANT]
> - Gmail scanner runs strictly in READ-ONLY mode (`gmail.readonly`). It must never send, modify, or delete any email messages.
> - Analysis is heuristic (header inspection & keyword matching). No full email body content is logged or permanently stored.

## Proposed Changes

### Component 1: Phishing Pattern Analyzer

#### [NEW] [`integrations/phishing_scan.py`](file:///Users/somespecies/Desktop/Evie/integrations/phishing_scan.py)
- Create module docstring referencing `SCORE-04` and Section 8 of `02_TRD.md`.
- Implement `analyze_email_header(headers: dict) -> dict`:
  - Inspect `From`, `Return-Path`, `Subject`, `Authentication-Results`.
  - Flag 1: Financial urgency keywords (`"urgent wire transfer"`, `"account suspended"`, `"verify password"`, `"security breach action required"`).
  - Flag 2: Domain mismatch (sender domain in `From` does not match `Return-Path` domain).
  - Flag 3: Authentication failure (DKIM `fail` or SPF `fail` in `Authentication-Results`).
  - Calculate `risk_score`: `'low'`, `'moderate'`, `'high'`, or `'critical'`.
  - Return indicator dict with flags and risk score.

- Implement `scan_phishing_patterns(messages: list[dict]) -> list[dict]`:
  - Iterate over input message headers list.
  - Run `analyze_email_header()`.
  - Filter messages with `risk_score` >= `'moderate'`.
  - Return list of flagged message findings.
