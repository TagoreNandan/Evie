# Plan 01-01: Keyring Vault & Redaction Utility

## Objective

Establish secure credential storage using Python's `keyring` library to interact with native OS secret vaults (macOS Keychain) and implement a mandatory secret redaction utility to prevent unredacted secrets from appearing in logs or database tables.

## Tasks

### Task 1: Implement Keyring Vault Wrapper (`keyring_utils.py`)
- **Type**: tracer
- **Description**: Create `keyring_utils.py` containing functions `set_credential(service: str, key: str, value: str) -> None`, `get_credential(service: str, key: str) -> str | None`, and `delete_credential(service: str, key: str) -> None`. Ensure no fallback to SQLite or plaintext file storage exists for credentials. Keyring unit tests in `tests/test_keyring.py` must explicitly mock the `keyring` package/backend (e.g., using `unittest.mock` or a dummy backend) and never create, read, or modify real OS / macOS Keychain credentials.
- **Files**:
  - `keyring_utils.py`
  - `tests/test_keyring.py`
- **Threat Model**:
  - *Risk*: Raw secret leakage or plaintext fallback if keyring is unavailable.
  - *Mitigation*: Raise explicit `RuntimeError` if OS keyring fails rather than creating unencrypted fallback files. Tests must use mocked backends to avoid mutating native macOS Keychain.
- **Automated Verification**: `pytest tests/test_keyring.py`

### Task 2: Implement Secret Redaction Helper (`redaction.py`)
- **Type**: task
- **Description**: Create `redaction.py` containing `redact_secret(val: str | None) -> str`. If `val` is `None`, `""`, or `len(val) <= 4`, return `"****"`. Otherwise, format as `f"{val[:2]}...{val[-2:]}"`. Add helper `redact_dict_secrets(d: dict) -> dict` for masking sensitive dictionary keys before logging. `redact_dict_secrets` MUST return a new dictionary without mutating the input dictionary `d`. Sensitive-key matching uses case-insensitive substring matching for keys containing any of: `token`, `secret`, `password`, `api_key`, `access_key`, `private_key`, `credential`.
- **Files**:
  - `redaction.py`
  - `tests/test_redaction.py`
- **Threat Model**:
  - *Risk*: Accidental unredacted secret printing in debug logs or in-place mutation of input dictionary.
  - *Mitigation*: Ensure `redact_secret` handles `None`, empty strings, and arbitrary lengths safely. Ensure `redact_dict_secrets` creates a clean shallow/deep copy and covers all case-insensitive sensitive key patterns.
- **Automated Verification**: `pytest tests/test_redaction.py`

## Verification Strategy

- Run unit test suite: `pytest tests/test_keyring.py tests/test_redaction.py`
