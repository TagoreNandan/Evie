# Plan 03-01: Daily Journal Ingestion & Shared Memory Engine (`memory.py`)

## Goal
Implement `memory.py` providing structured daily journal entry ingestion and SQLite persistence (`journal_entries` table) per `MEM-01`.

## User Review Required
> [!IMPORTANT]
> - All long-term memory operations MUST pass through `memory.py`.
> - Raw secrets or unredacted API tokens must never be written to `journal_entries` or logs.

## Proposed Changes

### Component 1: Shared Memory Service

#### [NEW] [`memory.py`](file:///Users/somespecies/Desktop/Evie/memory.py)
- Module docstring referencing Section 3 of `02_TRD.md` and `MEM-01`/`MEM-02`.
- Implement `init_memory_tables(db_path: str = "evie.db") -> None`:
  Create `journal_entries` and `journal_embeddings` SQLite tables per `04_Backend_Schema.md`.
- Implement `add_journal_entry(entry_date: str, content: str, source_data: dict | None = None, db_path: str = "evie.db") -> dict`:
  - Validate `entry_date` (`YYYY-MM-DD` format).
  - Validate non-empty `content`.
  - Filter `content` through `redaction.redact_dict_secrets()` or string redaction to ensure secret safety.
  - Insert entry into `journal_entries` table (`entry_date`, `content`, `source_data` as JSON string).
  - Generate text vector embedding (using `numpy` vector feature extractor).
  - Insert vector embedding into `journal_embeddings` table (`entry_id`, `entry_date`, `embedding_json`).
  - Return `{"id": entry_id, "entry_date": entry_date, "content": content, "status": "created"}`.

### Component 2: FastAPI Integration & Test Suite

#### [MODIFY] [`main.py`](file:///Users/somespecies/Desktop/Evie/main.py)
