## Proposed Changes

### Component 1: Vector Search Service Engine

#### [MODIFY] [`memory.py`](file:///Users/somespecies/Desktop/Evie/memory.py)
- Implement `compute_embedding(text: str) -> list[float]`:
  Local text vector encoder generating normalized vector embedding array using `numpy`.
- Implement `search_journal_entries(query: str, top_k: int = 5, start_date: str | None = None, end_date: str | None = None, db_path: str = "evie.db") -> list[dict]`:
  - Validate `query` non-empty.
  - Compute query vector embedding.
  - Query `journal_embeddings` table with optional `entry_date >= start_date` and `entry_date <= end_date` SQL clauses.
  - For each stored vector, compute cosine similarity score: `dot(q, v) / (norm(q) * norm(v))`.
  - Sort candidates by similarity score descending.
  - Join top `top_k` candidate IDs with `journal_entries` to retrieve text content and metadata.
  - Return list of dicts: `[{"id": 1, "entry_date": "2026-09-19", "content": "...", "score": 0.92}]`.

### Component 2: FastAPI Endpoint Integration

  - Call `memory.search_journal_entries(query=q, top_k=top_k, start_date=start_date, end_date=end_date, db_path=DB_PATH)`.
